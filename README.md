# Company Backend API (SQLAlchemy 2.0 + FastAPI + Alembic)

Backend εφαρμογή διαχείρισης χρηστών και εργασιών (Users & Tasks) κατασκευασμένη με σύγχρονο Python stack.

## Τεχνολογίες
* **Python 3.13**
* **SQLAlchemy 2.0** (ORM, Relationships, Session management)
* **Alembic** (Database Migrations)
* **FastAPI & Pydantic** (REST API & Validation)
* **SQLite**
